# 奶龙快跑 · NaiLong Run

一只圆滚滚的小奶龙，在草地森林里不停奔跑，躲开石块、树枝和小鸟，
用喷火把挡路的大树烧成灰。

**在线玩：** https://<你的用户名>.github.io/<仓库名>/

![游戏截图](screenshot.png)

## 操作

| 电脑 | 手机 |
|---|---|
| `空格` / `↑` 跳跃 | 点画面 / 「跳」按钮 |
| `↓` 下蹲（钻过小鸟） | 「蹲」按钮 |
| `E` 喷火（CD 10 秒，烧毁前方障碍） | 「火」按钮 |
| `Q` 重新开始 · `F5` 刷新 · `M` 静音 | 点画面重开 |

## 玩法

- 每个障碍 **+10 分**，满分 99999 后归零并触发**开发者彩蛋**
- 速度随分数线性提升（280 → 980 px/s，3000 分封顶）
- 昼夜每 90 秒循环一次，有太阳/月亮/星星
- 三种障碍：石块与树枝（可跳可烧）、**大树（跳不过去，只能烧）**、小鸟（要下蹲或烧）
- 每 100 分有音效提示；加速时奶龙会张嘴
